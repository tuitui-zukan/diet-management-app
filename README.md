# ダイエット管理アプリ（個人用PWA）

筋トレの実施チェック・小顔マッサージの実施チェック・週次の献立管理をひとつにまとめた個人用Webアプリ。

## 構成

```
ダイエットアプリ/
├── index.html        アプリ本体（3タブ構成）
├── css/style.css      デザイン
├── js/app.js          動作ロジック（データ保存・画面更新）
├── manifest.json       PWA設定（ホーム画面追加用）
├── service-worker.js   オフラインキャッシュ
└── icons/              ホーム画面アイコン
```

## 使い方

### 筋トレ／マッサージタブ
- 上のメモ欄に今週のメニュー・やり方を自由記述で入力（入力するたび自動保存）
- 「今日やった ✓」ボタンを押すとその日の実施が記録される。もう一度押すと取り消し
- 直近7日間の丸印と、これまでの累計実施日数を表示

### 献立タブ
- 「←前週／次週→」で週を切り替え（週の区切りは月曜始まり）
- 予算（円）と冷蔵庫の在庫メモを入力
- **この予算・在庫メモと、Instagramで保存したメニュー候補（スクリーンショット推奨）をClaudeに渡すと、予算内・栄養バランス・食材の使い切りを考慮した1週間の献立を作成できる**
- Claudeが作った献立を「今週の献立」欄に貼り付けて保存
- 各曜日のチェックボックスで「予定通り実行したか」を記録
- 実際にかかった金額を入力すると、予算との差額を自動計算（予算内は緑、オーバーは赤で表示）

## データの保存について

- すべてのデータはこの端末（ブラウザ）の **localStorage** に保存される
- サーバーには一切送信されない。他の端末とは共有されない（iPhoneとPCで別々のデータになる）
- ブラウザのデータ消去やアプリの再インストールでデータが消える点に注意

## 動作確認（Windows上でまず確認する場合）

`index.html` をダブルクリックしてブラウザで開けば、PC上で全機能を確認できる（Service Workerとホーム画面追加はスマホでのみ意味を持つ機能なので、PC確認時は無視してよい）。

## iPhoneから使うために（要確認）

iPhoneのSafariは `file://` 経由でWindows PC内のファイルに直接アクセスできないため、iPhoneから開くには何らかの方法で「URLとして」配信する必要がある。主な方法：

| 方法 | 特徴 |
|---|---|
| PC上でローカルサーバーを起動し、同じWi-Fi内のiPhoneからアクセス | 無料・即座に試せる。PCの起動中＆同じWi-Fi内でしか使えない |
| GitHub Pagesなどの無料ホスティングにデプロイ | 常時どこからでもアクセス可能。外部への公開作業（リポジトリ作成・push）が必要 |

データ自体はlocalStorageで端末内に閉じるため、コード（見た目や機能のみ）を外部ホスティングに置いても個人情報が漏れる心配はない。どちらの方法にするかは別途相談のうえ進める。

## iPhoneホーム画面への追加方法（配信URLが決まったあと）

1. SafariでアプリのURLを開く
2. 共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選択

これでアイコンをタップするだけでアプリのように開けるようになる。
